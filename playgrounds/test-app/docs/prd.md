# 订单管理系统 PRD

## 概述

本系统用于管理电商订单的全生命周期，从下单到交付的完整流程。当前系统已有用户管理和认证模块，本次 PRD 聚焦订单和退款能力。

## 功能需求

### 订单创建

用户选择商品后，系统生成订单并锁定库存。支持多商品、多收货地址。

### 订单状态追踪

用户可实时查看订单状态：待付款 → 已确认 → 已发货 → 已签收。

### 退款处理

支持全额退款和部分退款。退款金额原路返回。需人工审核大额退款（>5000元）。

### 订单取消

用户可在发货前取消订单，系统自动释放库存。

## 非功能需求

- 订单创建接口响应时间 < 500ms (P99)
- 退款流程需要完整的操作日志，可审计
- 订单数据保留 2 年，超期归档

## 技术约束

- 数据库：PostgreSQL 15
- 缓存：Redis Cluster 7.x
- 消息队列：Kafka 用于订单状态变更通知
- 已有注册/登录/用户管理 API，本次不修改
