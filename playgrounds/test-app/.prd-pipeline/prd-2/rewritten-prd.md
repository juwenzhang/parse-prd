# 协同低代码编辑器
> AI 重写版本 · 1.0

## 背景
运营经常需要快速上线活动页、促销页，但开发排期跟不上，一个简单页面最快需要3天。去年就有需求，现在老板挂名，竞品已经领先，必须加快推进。

## 功能需求
### FR-1 画布编辑 `P2`
用户可以在画布上拖拽组件，调整位置、大小和样式，支持网格对齐、吸附线、缩放、多选、图层管理、撤销重做和常用快捷键。

**验收标准：**
- 拖拽组件到画布上后可以移动和调整大小
- 画布显示网格线，组件靠近时出现吸附线
- 支持画布缩放（如50%-200%）
- 按住Shift可多选组件并一起移动
- 提供图层列表，可调整层级顺序
- 支持撤销（Ctrl+Z）和重做（Ctrl+Shift+Z），最多20步
- 支持Ctrl+C/V复制粘贴，Ctrl+D原地复制

### FR-2 组件系统 `P2`
提供丰富的组件库，包括文本、图片、按钮、输入框、表格、轮播图等，组件支持嵌套和Flex布局，每个组件有独立的属性面板，可编辑内容、样式和事件。

**验收标准：**
- 组件面板展示所有可用组件，可拖入画布
- 支持容器组件（如div）嵌套其他组件
- 选中组件后右侧显示属性面板，可修改文字、颜色、大小等
- 支持Flex布局属性（方向、对齐、间距）
- 按钮组件可绑定点击事件（暂不实现复杂逻辑）

### FR-3 页面管理 `P2`
用户可以创建、编辑、预览、发布和删除页面，支持页面列表、搜索和分类，发布前可预览真实效果，支持版本管理和回滚。

**验收标准：**
- 在页面列表可查看所有页面，支持按名称搜索和分类筛选
- 创建新页面后进入编辑器
- 编辑过程中自动保存为草稿
- 发布前可预览页面真实交互效果
- 发布后生成可访问的URL
- 保留最近10个历史版本，支持回滚到任一版本

### FR-4 协同编辑 `P2`
多人可同时编辑同一页面，实时看到其他用户的光标和正在编辑的组件，支持编辑锁避免冲突，提供编辑者和观察者权限。

**验收标准：**
- 同一页面允许多人同时在线编辑
- 能看到其他协作者的光标位置和选中组件
- 当用户正在编辑某组件时，该组件被锁定，其他人不可修改
- 页面管理员可邀请他人协作，设置编辑者或观察者权限
- 观察者只能查看，不能修改

### FR-5 数据管理 `P2`
页面数据以JSON格式存储，支持自动保存草稿、发布和版本管理，后端提供CRUD和版本回滚API。

**验收标准：**
- 编辑过程中修改自动保存到后端（防丢失）
- 页面数据结构为描述组件树的JSON
- 发布操作将当前草稿转为发布版本
- 版本列表显示版本号和创建时间，可选择回滚

## 领域实体
### 页面
| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 页面唯一标识 |
| title | string | 页面名称 |
| status | enum | 页面状态：草稿、已发布、已删除 |
| data | json | 存储页面组件树的JSON数据 |
| version | number | 当前版本号 |
| createdAt | datetime | 创建时间 |
| updatedAt | datetime | 最后更新时间 |

### 组件
| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 组件实例唯一标识 |
| type | string | 组件类型，如 Text, Button |
| props | json | 组件属性和样式配置 |
| children | array | 子组件列表 |
| parentId | string | 父组件ID |

### 版本
| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 版本唯一标识 |
| pageId | string | 关联的页面ID |
| versionNumber | number | 版本序号 |
| data | json | 该版本的页面JSON数据 |
| createdAt | datetime | 版本创建时间 |

### 协作会话
| 字段 | 类型 | 说明 |
|------|------|------|
| pageId | string | 正在协作的页面ID |
| participants | array | 参与者列表，每人包含用户信息和光标位置 |
| activeLock | object | 当前被锁定的组件ID及锁定者 |

## 技术约束
- 前端使用 React 框架
- 数据存储使用 PostgreSQL，大JSON可考虑对象存储
- 协同通信采用 WebSocket
- 缓存使用 Redis
- API 不能与现有 /register, /login, /logout 等冲突，需使用新路由前缀如 /pages

## 术语表
- **画布**：可视化编辑区域，用户在此拖拽和编排组件
- **组件**：可复用的页面元素，如文本框、图片、按钮等
- **属性面板**：选中组件后右侧显示的配置面板，可编辑组件属性和样式
- **OT/CRDT**：实时协同编辑中解决冲突的两种算法
- **版本回滚**：将页面恢复到某个历史版本的操作
