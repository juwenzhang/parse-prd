## 阶段1: MVP核心功能
### 用户端订单模块
- [ ] 用户可以提交订单并完成支付，生成订单记录
- [ ] 用户可以查看自己的订单列表，支持按状态（待付款、待发货、已发货、已完成等）筛选
- [ ] 用户可以点击订单查看详细信息（商品、金额、收货地址、物流单号、订单状态时间线）
- [ ] 用户在未付款或未发货状态下可以主动取消订单

### 管理端订单模块
- [ ] 管理员可以查看所有用户的订单列表，支持按订单号、用户信息、状态等条件搜索和分页浏览
- [ ] 管理员可以查看任一订单的完整详情，包括商品、金额、用户信息、操作历史
- [ ] 管理员可以推进订单状态：确认付款、标记发货、完成订单，或根据需要取消订单
- [ ] 管理员可以处理用户的退款申请，进行退款操作并更新订单状态

## 阶段2: 增强功能
### 用户端订单模块
- [ ] 用户可以对已完成的订单进行商品评价和晒单
- [ ] 用户可以在收货后发起退货／退款售后申请，并可查看处理进度
- [ ] 用户可以在订单详情中查看物流实时追踪信息（如接入快递100）
- [ ] 用户在特定状态下（如未发货）可以修改收货地址或备注信息

### 管理端订单模块
- [ ] 管理员可以批量操作订单，如批量发货、批量打印发货单、批量导出订单excel
- [ ] 管理员可以查看订单统计报表（日／周／月销售订单量、金额、退货率等）
- [ ] 管理员可以对订单添加内部备注（如异常标记、客服备忘）
- [ ] 管理员可以录入或修改物流单号，支持批量导入物流信息

## 阶段3: 体验优化
### 用户端订单模块
- [ ] 订单列表支持下拉刷新和页面加载骨架屏，提升加载感知
- [ ] 关键订单状态变更时通过站内信／短信／push通知用户（如支付成功、已发货）
- [ ] 订单详情页中运单号支持一键复制，物流跟踪页面可跳转至快递官网
- [ ] 订单取消时提供快捷原因选择，并可收集用户补充说明，降低流失

### 管理端订单模块
- [ ] 订单列表增加高级筛选（时间范围、金额区间、商品名称等），并保存常用筛选条件
- [ ] 订单状态变更增加二次确认弹窗，关键操作（如取消、退款）记录操作日志备查
- [ ] 标注异常订单（如长时间未支付、地址不详）并予以高亮提醒，方便优先处理
- [ ] 后台订单管理界面适配平板和移动端响应式布局，支持移动办公
