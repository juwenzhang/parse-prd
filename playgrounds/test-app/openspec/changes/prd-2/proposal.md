## Data Models
- **页面**: 用户创建的页面，包含组件树 JSON 数据、状态和基本元信息。 (id)
- **页面版本**: 页面的历史版本快照，记录某一时刻的完整页面数据。 (id, pageId)
- **组件类型**: 系统预定义的组件模板，描述组件名称、类别、默认属性和可配置项。 (type)
- **协作会话**: 记录某个页面当前的所有在线协作者、光标位置和组件锁定状态。 (pageId)
