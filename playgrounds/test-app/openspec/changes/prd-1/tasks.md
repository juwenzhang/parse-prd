## 阶段1: MVP核心功能
### anchor-live-management
- [ ] 主播能够创建直播间并填写基础信息（标题、封面、开播时间）
- [ ] 主播可一键开播，向观众推送直播通知
- [ ] 主播可手动结束直播并保存回放

### live-interaction
- [ ] 观众能够在直播间发送文字弹幕并实时显示
- [ ] 观众可以对直播进行点赞（爱心飘动效果）
- [ ] 主播端可查看当前在线观众列表

### live-purchase
- [ ] 主播可在直播中展示商品卡片（商品图、名称、价格）
- [ ] 观众可点击商品卡片加入购物车
- [ ] 观众能在直播界面直接完成下单和基础支付

### live-analytics
- [ ] 主播可实时查看当前观看人数与累计观看次数
- [ ] 主播可看到当前在线人数趋势图
- [ ] 主播收到订单成交的即时提醒

### admin-danmaku-filter
- [ ] 系统默认应用敏感词库自动拦截违规弹幕
- [ ] 被拦截弹幕不显示在公屏，只记录后台日志

## 阶段2: 增强功能
### anchor-live-management
- [ ] 主播可配置美颜、滤镜和画面镜像
- [ ] 主播可创建系列直播计划并自动预告
- [ ] 主播可设置直播间管理员协助控评

### live-interaction
- [ ] 观众可赠送虚拟礼物并触发全屏特效
- [ ] 主播可发起红包或抽奖活动，观众参与抽选
- [ ] 弹幕支持@特定观众和彩色字体

### live-purchase
- [ ] 主播可设置限时秒杀活动并倒计时抢购
- [ ] 观众可领取和使用直播间专属优惠券
- [ ] 观众可查看自己的历史直播订单和物流状态

### live-analytics
- [ ] 主播可查看直播间的转化漏斗（曝光-点击-下单）
- [ ] 主播可导出单场直播的商品销售报表
- [ ] 主播可查看观众地域、年龄等基础画像分析

### admin-danmaku-filter
- [ ] 管理员可自定义添加敏感词及替换规则
- [ ] 支持正则表达式匹配复杂变体词汇
- [ ] 可对频繁违规用户自动临时禁言

## 阶段3: 体验优化
### anchor-live-management
- [ ] 主播可编辑已结束直播的回放并再次发布
- [ ] 主播可提前录制预告视频并设置开播提醒
- [ ] 主播端网络状态和画质自适应提示

### live-interaction
- [ ] 观众可获得粉丝勋章，长期互动提升勋章等级
- [ ] 直播间显示互动排行榜（贡献榜、点赞榜）
- [ ] 长按点赞可触发连击特效

### live-purchase
- [ ] 观众可对已购商品进行晒单评价
- [ ] 自动填写收货地址并支持多地址管理
- [ ] 购物车在断网恢复后保持数据不丢失

### live-analytics
- [ ] 主播可生成多维度数据报表并自定义日期对比
- [ ] 支持大屏投屏模式实时展示关键指标
- [ ] 邮件订阅周期性直播数据报告

### admin-danmaku-filter
- [ ] 观众可对误拦截弹幕发起申诉，管理后台可审核
- [ ] 支持白名单用户/关键词直接放行
- [ ] 提供批量导入/导出敏感词库的功能
