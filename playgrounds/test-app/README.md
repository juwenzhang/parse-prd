# test-app

Generated by `lhx-cli create --template=node-ts` on 2026.

A minimal Node.js + TypeScript service. No web framework included — add
Express, Fastify, Koa, or any other layer on top when you need it.

## Scripts

```bash
pnpm dev          # tsx watch — restarts on file change
pnpm build        # tsc prod build → dist/
pnpm start        # node dist/main.js
pnpm typecheck    # tsc --noEmit
pnpm lint         # biome check
```

## Docker

```bash
docker build -t test-app .
docker run --rm -e NODE_ENV=production test-app
```

## Environment variables

Copy `.env.example` to `.env` and fill in values:

| Variable  | Default       | Description      |
| --------- | ------------- | ---------------- |
| NODE_ENV  | `development` | Runtime mode     |
| LOG_LEVEL | `info`        | pino log level   |
